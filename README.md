# MicroTools Hub

Twelve everyday tools that run 100% in the browser. No signup, no uploads, no analytics, no server calls after load - works offline.

Live: https://airdropia.github.io/microtools-hub/

## Tools

Word & character counter - Strong password generator (Web Crypto) - JSON formatter/validator - WCAG color contrast checker - Text case converter - URL slug generator - Unit converter - Age & date calculator - Percentage calculator - Lorem ipsum generator - Base64/URL encoder - SHA hash checker

## How it runs

Single static `index.html`, deployed by GitHub Pages from `main`. Zero build step, zero dependencies, zero cost.
